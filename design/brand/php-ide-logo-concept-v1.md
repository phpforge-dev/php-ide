# PHP IDE — logo v1

Criada com a ferramenta integrada image_gen. PNG com fundo transparente; conceito para revisão visual. Arquivo: php-ide-logo-concept-v1.png. Aplicada ao aplicativo: public/brand/php-ide-logo.png, abertura, boas-vindas, barra do projeto e ícones nativos gerados pelo CLI Tauri.

## Prompt utilizado

Use case: logo-brand. Asset type: original logo symbol for PHP IDE, an open source desktop development environment built in Rust and Tauri. Primary request: design one polished, memorable standalone logo mark for this project, suitable for the macOS app icon, IDE welcome screen, and compact toolbar. Subject: a confident geometric monogram P whose negative space subtly evokes code brackets and connected navigation through code. Style: precise vector-like flat brand design, restrained and contemporary, crisp contours, balanced optical weight, visually distinctive silhouette, excellent legibility at small size. Composition: one centered symbol on a square canvas, generous consistent transparent margins. Constraints: genuinely transparent background; no wordmark, no letters besides the integrated P monogram, no captions, no mockup, no presentation board, no decorative objects, no gradients requiring fine detail, no tiny details. Create an independent identity; do not reproduce JetBrains or PhpStorm logos. Deliver one finished symbol, not a grid of options.


## Aplicação em 22/10/2026

Fonte de distribuição: `public/brand/php-ide-logo.png`. Ícones nativos gerados com `node scripts/tauri.mjs icon public/brand/php-ide-logo.png` em `src-tauri/icons/`; o bundle declara explicitamente PNG, ICNS e ICO. A logo está na abertura animada, boas-vindas, favicon e barra do projeto. A imagem gerada original permanece preservada. Os previews claro/escuro e da abertura foram conferidos; typecheck e 22 testes Rust passaram.
