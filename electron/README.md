# Implementação anterior (histórica)

Este diretório preserva a implementação Electron/Node anterior à migração para Rust/Tauri. Não integra o runtime, build ou testes atuais. O backend ativo está em `src-tauri/src`; os parsers e plugins puros reaproveitados estão em `shared/language`. Testes TypeScript antigos em `tests/` e scripts `check-*-ui.ts` documentam contratos anteriores e não comprovam o backend Rust.
